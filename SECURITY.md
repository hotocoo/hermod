# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub security advisories: go to the repository's Security tab and choose "Report a vulnerability".

Include what you found, how to reproduce it, and the version. We will acknowledge the report and work with you on a fix and a coordinated disclosure.

## Scope

Hermod is peer-to-peer and encrypted per space. Known design limits (no member removal, no invite revocation, metadata such as IP addresses visible to peers) are documented in the README and are not vulnerabilities.

## Supported versions

Only the latest release receives fixes.
